# Hi, I'm Denys 👋

I like building things — software companies, embedded gadgets, and occasionally questionable Bitcoin scripts.

By day I run [EltexSoft](https://eltexsoft.com), an engineering consultancy I founded. By night I'm usually soldering something to an Arduino or pulling apart a Raspberry Pi project that definitely didn't need to be this complicated.

I advise startups and Fortune 500 engineering teams, write for [Forbes](https://councils.forbes.com/profile/Denys-Vorobyov-Founder-CEO-EltexSoft/e2640c9c-45c2-4a38-a0a9-f47b58b19a12), and have been quoted in the [Financial Times](https://ft.com/content/6a23a27c-3500-11e5-b05b-b01debd57852) — but I'm most at home when I'm debugging something at 2am.

### What I'm tinkering with

- 🔧 Hardware — Arduino, Raspberry Pi, IoT prototypes, home automation
- ₿ Bitcoin tooling — key extraction, puzzle challenges, cryptography
- 🏗️ Infrastructure — self-hosted stacks, Docker, Coolify, Ghost CMS
